Getting started

What Skell Client is, what you need to run it and how it will install.

What Skell Client is

Skell Client is a Fabric client mod for Minecraft 1.21.11. It adds a glass-style mods menu, an HUD editor that remembers where every widget belongs, more than 140 modules, synced lyrics, a recorder and 30-second clips. It is developed independently by Take.

Public launch coming soon

Skell Client is under constant development and will be public soon. These guides describe version 0.15.1, so you can see what to expect before the download is available.

Requirements

ComponentVersion
Minecraft1.21.11
Fabric Loader0.20.1
Fabric API0.141.6
Java21

The recorder, the 30-second clips and the system music session need Windows. The rest of the client does not depend on the operating system. On the mobile launchers PojavLauncher and MojoLauncher the client detects the device and adds touch scrolling; see Troubleshooting for what is not available there.

Installing

  1. 1
    Install Fabric Loader 0.20.1 for Minecraft 1.21.11 with the Fabric installer.
  2. 2
    Put Fabric API 0.141.6 in the mods folder of your Minecraft directory.
  3. 3
    Put skell-client-0.15.1.jar in the same folder.
  4. 4
    Remove any earlier Skell Client jar. Older builds are the same mod under another id, and only one can be installed.
  5. 5
    Start the game and press Right Shift to open the mods menu.

The download is not published yet. Until it is, this list shows how the installation will work.

Your settings carry over

On first start the client copies the settings, profiles, checkpoints and macros of the previous name to the new one, and moves your saved keys. Nothing is deleted from the old location.

First launch

Every module starts switched off, so the game looks exactly like Minecraft until you choose what to use. A good first session:

  1. 1
    Open the menu with Right Shift and look at the HUD page. Switch on FPS, Coordinates or any widget you want.
  2. 2
    Open the Edit HUD screen from the bottom of the sidebar and drag each widget where you like it.
  3. 3
    Press the settings button of a module to see its live preview and every setting, grouped.
  4. 4
    Save the result as a profile in Profiles, so you can restore or share it later.
