01¿Cómo empiezo?+

Consulta la guía de primeros pasos para conocer las versiones de Minecraft, Fabric y Java requeridas.

02¿Dónde encuentro ayuda?+

La guía de solución de problemas cubre el inicio, los controles y la configuración.

03¿Puedo probar la interfaz en el navegador?+

Sí. El estudio incluye el menú de módulos y varias vistas interactivas.

04¿Cómo muevo los widgets del HUD?+

Abre el editor HUD y arrastra un widget. Hay guías, ajuste automático y movimiento con el teclado.

05¿Qué versión de Minecraft es compatible?+

Esta versión de Skell Client funciona con Minecraft 1.21.11 y Fabric.

06¿Qué versión de Java necesito?+

Usa Java 21 con las versiones compatibles de Fabric Loader y Fabric API.

07¿Qué puedo cambiar en la interfaz?+

Puedes ajustar el diseño, los colores, las animaciones y el idioma.

08¿Dónde están los módulos disponibles?+

La referencia de módulos se puede buscar y describe las opciones por categoría.

09¿Puedo previsualizar un efecto visual?+

Abre Efectos de eliminación en el estudio y elige un efecto para ajustar su vista previa.

10¿Cómo funciona la repetición instantánea?+

La guía de música y capturas explica la repetición, la grabación y la biblioteca.

11¿El sitio está disponible en español?+

Sí. El selector de idioma cambia la portada y la documentación.

12¿Qué cambió en esta versión?+

Las novedades detallan los cambios en la interfaz, el HUD, los efectos y las herramientas.

13¿Quién desarrolla Skell Client?+

Take desarrolla Skell Client de forma independiente.

14¿Es un producto oficial de Minecraft?+

Skell Client es independiente de Mojang Studios y Microsoft.
