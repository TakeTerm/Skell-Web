01How do I get started?+

Check the getting-started guide for the required Minecraft, Fabric, and Java versions.

02Where do I find support?+

The troubleshooting guide covers startup issues, controls, and common configuration questions.

03Can I try the interface in a browser?+

Yes. The studio includes browser versions of the mods menu and several client previews.

04How do I move my HUD widgets?+

Open the HUD editor, then drag a widget. You can use snapping, guides, and keyboard nudging.

05Which Minecraft version is supported?+

This edition of Skell Client is built for Minecraft 1.21.11 on Fabric.

06Which Java version is required?+

Use Java 21 with the supported Fabric Loader and Fabric API versions.

07What can I change in the interface?+

The client offers settings layouts, accent colours, animations, and language controls.

08Where can I see the available modules?+

The searchable module reference lists modules by category and describes their settings.

09Can I preview a visual effect?+

Open Kill Effects in the studio and select an effect to adjust its browser preview.

10How does instant replay work?+

The music and captures guide covers instant replay, recording, and the recordings library.

11Is the site available in Spanish?+

Yes. Use the language selector to switch both the landing page and documentation.

12What changed in the current version?+

The changelog lists changes to the interface, HUD, visual effects, and client tools.

13Who develops Skell Client?+

Skell Client is independently developed by Take.

14Is this an official Minecraft product?+

Skell Client is independent of Mojang Studios and Microsoft.
